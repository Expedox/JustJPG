JustJPG – Privacy Policy

Last updated: 26 September 2026 ·

EnglishDeutsch

Summary

JustJPG does not collect, store, sell or transmit any personal data. Everything the extension does happens locally in your browser.

What the extension does with data

  • Images: When you ask JustJPG to save an image, it downloads that image from the website's own server (the same server your browser already loaded it from), converts it to JPG on your computer and saves it to your download folder. Images are never sent to the developer or any third party.
  • Web pages: The extension looks at the page only to find the image you point at and to show its optional button. To name the saved file it can use the page title, the site's domain and the image's description (alt text) – only locally, according to your file name setting. It does not store or send page content, form input or your browsing history.
  • Settings: Your preferences (quality, file name pattern, language, etc.) are saved with Chrome's storage. If you use Chrome Sync, Chrome may sync these settings between your own devices through your Google account; the developer has no access to them.
  • Screenshots: If an image cannot be downloaded, JustJPG can take a screenshot of the visible tab and crop the image from it. The screenshot is processed in memory and only the cropped JPG is saved to your computer.

What the extension does not do

  • No accounts, no sign-in
  • No analytics, telemetry, tracking or advertising
  • No remote code – all code, including the HEIC decoder, ships inside the extension
  • No sale or transfer of data to anyone

Permissions

The permissions JustJPG requests are used only for the purpose described above: finding, converting and saving images. A detailed explanation of every permission is part of the Chrome Web Store listing.

Kurzfassung

JustJPG erhebt, speichert, verkauft oder überträgt keine personenbezogenen Daten. Alles, was die Erweiterung tut, passiert lokal in deinem Browser.

Was die Erweiterung mit Daten macht

  • Bilder: Wenn du JustJPG ein Bild speichern lässt, lädt die Erweiterung dieses Bild vom Server der Webseite (demselben Server, von dem dein Browser es ohnehin geladen hat), wandelt es auf deinem Rechner in JPG um und legt es in deinen Download-Ordner. Bilder werden niemals an den Entwickler oder Dritte gesendet.
  • Webseiten: Die Erweiterung schaut sich die Seite nur an, um das Bild zu finden, auf das du zeigst, und um ihren optionalen Knopf anzuzeigen. Für den Dateinamen kann sie Seitentitel, Domain und Bildbeschreibung (alt-Text) verwenden – nur lokal und je nach deiner Dateinamen-Einstellung. Seiteninhalte, Formulareingaben oder dein Browserverlauf werden weder gespeichert noch gesendet.
  • Einstellungen: Deine Einstellungen (Qualität, Dateinamen-Muster, Sprache usw.) werden im Speicher von Chrome abgelegt. Nutzt du Chrome Sync, kann Chrome sie über dein Google-Konto zwischen deinen eigenen Geräten abgleichen. Der Entwickler hat darauf keinen Zugriff.
  • Screenshots: Lässt sich ein Bild nicht herunterladen, kann JustJPG einen Screenshot des sichtbaren Tabs machen und das Bild daraus ausschneiden. Der Screenshot wird nur im Arbeitsspeicher verarbeitet, gespeichert wird nur das ausgeschnittene JPG auf deinem Rechner.

Was die Erweiterung nicht tut

  • Keine Konten, keine Anmeldung
  • Keine Statistik, Telemetrie, kein Tracking, keine Werbung
  • Kein nachgeladener Code – der gesamte Code einschließlich HEIC-Decoder ist in der Erweiterung enthalten
  • Kein Verkauf und keine Weitergabe von Daten an irgendwen

Berechtigungen

Die Berechtigungen von JustJPG werden ausschließlich für den oben beschriebenen Zweck verwendet: Bilder finden, umwandeln und speichern. Eine ausführliche Erklärung jeder Berechtigung steht im Eintrag im Chrome Web Store.
